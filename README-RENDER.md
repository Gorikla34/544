# Gift House — Render

This package is based on the latest uploaded Gift House project. The UI/source files are preserved; only the Manus/Vite runtime pieces that prevented independent deployment were removed.

Render Static Site settings:
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`
- Start Command: leave empty

The project is a Vite/React SPA and includes a rewrite to `/index.html` for client-side routes.
